ADVANCE 0.2
============

Native Game Boy Advance library frontend for mGBA on Nintendo Switch.

Default paths:
  ROMs: sdmc:/mGBA/Roms
  mGBA: sdmc:/switch/mgba.nro

HOME
  A Play   X Details   Y Favorite   R Surprise Me
  L Library   - Search   + Settings   B Exit

LIBRARY
  D-pad Browse   A Play   X Details   Y Sort
  L Favorites   R Recent   ZL/ZR Page   B Home

DETAILS
  A Play   Y Favorite   X Edit title   R Collections
  ZR Complete   ZL Hide   - Auto title   B Back

Optional per-game metadata:
  Put advance.json beside the ROM. See advance.json.example in
  sdmc:/switch/advance for the supported schema.

Advance never downloads, renames, patches, or modifies your ROM files.
