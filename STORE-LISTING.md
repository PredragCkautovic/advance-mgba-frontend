# Advance 0.1 — Store listing draft

## Name
Advance

## One-line summary
A personal, OLED-first Game Boy Advance library experience for mGBA on Nintendo Switch.

## Short description
Advance turns an existing mGBA collection into a polished console-style library with a personalized Home screen, cover art, smart and custom collections, ROM-hack metadata, favorites, search, completion/history tracking, themes, dynamic artwork backdrops, Switch profile integration and fast controller/touch navigation.

## Important dependency note
Advance is a frontend, not an emulator. mGBA must be installed separately. Advance does not include or download ROMs, BIOS files, commercial artwork, patches or mGBA itself. Users provide their own legally obtained game dumps and artwork.

## Highlights
- Native Nintendo Switch homebrew NRO
- OLED-focused Home and Library experiences
- Real Switch profile nickname/avatar when available
- Continue Playing, Recently Added, Favorites and Most Played shelves
- Smart and user-created collections
- ROM-hack-friendly `advance.json` metadata
- Metadata-aware Search
- Completion, hidden-game, launch-count and approximate play-time history
- Six built-in visual themes
- Game-reactive artwork backdrops
- UI sound and motion controls
- Touch support
- Safe, non-destructive library scanning

## Default paths
```text
mGBA: sdmc:/switch/mgba.nro
ROMs: sdmc:/mGBA/Roms
```
Both are configurable in `config.ini`.
